# Hotel-Room-Reservation-System
Hotel Room Reservation System that allocates rooms based on proximity and travel time. It first assigns rooms on the same floor, else selects across floors minimizing time (1 min/room, 2 min/floor). Includes UI for booking, viewing availability, random occupancy, and reset, showing efficient logic and visualization.

## Technology Used
Frontend: HTML, CSS, JavaScript / React.js
Styling: Tailwind CSS or Bootstrap
Backend (optional): Node.js, Express.js
Tools: VS Code, GitHub
Deployment: Vercel / Netlify

##  Features
Book up to 5 rooms at a time
Smart room allocation (same floor priority)
Minimum travel time calculation
Visual room layout (grid view)
Color indicators (Available / Occupied / Booked)
Random occupancy generator
Reset booking option
Simple and user-friendly interface
